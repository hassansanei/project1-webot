# project1-webot
# پروژه دنبال‌کردن هدف رنگی در Webots

این پروژه شامل پیاده‌سازی یک ربات e-puck در شبیه‌ساز Webots است که با استفاده از دوربین، یک هدف قرمز رنگ را تشخیص داده و آن را دنبال می‌کند.

## 🎯 ویژگی‌ها
- تشخیص رنگ قرمز با استفاده از پردازش تصویر
- کنترل حرکت دیفرانسیلی ربات
- پیاده‌سازی منطق جستجو برای یافتن هدف

## 🛠️ پیش‌نیازها
- نرم‌افزار Webots (نسخه R2023b یا جدیدتر)
- پایتون 3 (برای اجرای کنترل‌کننده)
